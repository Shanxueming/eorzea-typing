# 背景音乐（BGM）

把已获授权、可循环播放的背景音乐放在这个目录，刷新页面即可生效。游戏会自动扫描目录并显示当前曲名；不需要固定文件名。

```
assets/audio/任意曲名.mp3
assets/audio/任意曲名.ogg
assets/audio/任意曲名.flac
```

支持 MP3、OGG、WAV、M4A、AAC、FLAC；浏览器无法解码的文件会自动跳过。每局开始时随机抽一首，右上角可手动切换下一首。建议时长 60–180 秒、文件小于 5 MB，并在循环首尾预留无缝衔接。游戏仅在单机或联机战斗期间播放 BGM；右上角会显示当前曲名，并提供“下一首”“BGM 开 / 关”“音效开 / 关”和全局音量滑杆。音量默认 100%，即保持原有 BGM 0.25 与音效强度；选择保存在当前浏览器。

请只放入你拥有版权、授权或可合法使用的音频；如需署名，请在 `assets/CREDITS.md` 补充来源与授权信息。

## 这个目录不进版本控制

`.gitignore` 与 `.dockerignore` 都排除了本目录下的音频文件（只保留本 README 与 `.gitkeep`）。音频体积远大于全部代码，且授权状态因人而异，所以不随仓库分发、也不打进部署镜像——**线上环境没有 BGM**，前端静默降级。放在这里的文件只对你自己的本地环境生效。
