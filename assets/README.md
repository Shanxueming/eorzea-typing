# 素材目录

**这个目录下的所有文件都是可选的。** 游戏在素材完全缺失时必须正常运行,
自动降级到 CSS 图形与 Web Audio 合成音效。你可以随时把文件丢进来,刷新页面即生效。

---

## 多套皮肤(可选)

`avatar/p1.png`、`avatar/p2.png`、`effects/rabbit.png` 都支持放多套供玩家在主菜单选择:
1 号沿用原文件名,2 号及以后加数字后缀,例如:

```
avatar/p1.png     ← 1 号(默认)
avatar/p1-2.png   ← 2 号
avatar/p1-3.png   ← 3 号
avatar/p2-2.png
effects/rabbit-2.png
```

最多探测到 6 号(见 `apps/web/src/engine/assets.ts` 的 `MAX_SKIN_INDEX`),不需要连续,
放几张就出现几个选项;只有 1 张(或没有)时主菜单不显示选择器。玩家的选择存在浏览器
本地(localStorage),不是联机协议字段,双方各自本地生效,互不影响也不会同步。

## 需要准备的五个素材

### 1. 玩家小人 · `avatar/p1.png`

界面底部的角色,打对时放大跳动、打错时摇晃。

| 项 | 建议 |
|---|---|
| 尺寸 | 96×96 或 128×128 px(显示为 72×72,留 2x 余量) |
| 格式 | PNG,**透明背景** |
| 构图 | 角色**完整居中**,四周留约 8% 空白。不要贴边,否则放大动画会被裁切 |
| 朝向 | 正面或朝右。两个小人并排时朝向一致即可 |
| 风格 | 像素风观感最好(代码已设 `image-rendering: pixelated`),但普通截图也可用 |

**缺失时**:降级为一个 56px 的圆角方块,填充主题青色,内含昵称首字。

### 2. 对手小人 · `avatar/p2.png`

联机时右侧的第二个角色。可以和 `p1.png` 用同一张图,也可以换个配色以便区分。
规格同上。

**缺失时**:降级为灰色圆角方块。

### 3. 兔子 · `effects/rabbit.png`

打错时从小人头顶弹出,停留约 600 毫秒后消失。

| 项 | 建议 |
|---|---|
| 尺寸 | 64×64 px |
| 格式 | PNG,**透明背景** |
| 构图 | 主体占满画面,不留大片空白(显示尺寸只有 32px 左右,太小会看不清) |

**缺失时**:降级为一个图标或 CSS 气泡。

### 4. Boss 剪影 · `boss/titan.svg`

显示在 Boss 名称左侧,约 28×28 px。

| 项 | 建议 |
|---|---|
| 格式 | SVG 优先(可跟随主题变色),PNG 亦可 |
| 构图 | **单色剪影**效果最好,避免复杂细节——尺寸很小,细节会糊成一团 |

**推荐来源**:[game-icons.net](https://game-icons.net) 有 4000 多个免费游戏向 SVG 图标,
可在线改色后下载,采用 CC BY 3.0 协议。**使用时必须在 `CREDITS.md` 中署名原作者与链接。**

**缺失时**:不显示图形,只显示 Boss 名称文字。

### 5. 背景音乐 · `audio/` 下任意曲名

循环播放,默认音量 0.25,受静音开关控制。

| 项 | 建议 |
|---|---|
| 格式 | MP3、OGG、WAV、M4A、AAC、FLAC；自动扫描目录 |
| 时长 | 60–180 秒,**需要能无缝循环** |
| 体积 | 建议 3 MB 以内,否则首屏加载会变慢 |

**缺失时**:不播放，BGM 开关仍然显示；音效开关不受影响。右上角可查看当前曲名与切换下一首。详细投放说明见 [`audio/README.md`](audio/README.md)。

## 音效不需要素材

打对、打错、打断成功、受伤四种音效**全部由 Web Audio API 实时合成**,
不依赖任何音频文件,也不引入音频库。想调整音色,改 `apps/web/src/engine/audio.ts` 里的
振荡器类型、频率与包络参数即可。

这样做的好处:零下载、零体积、零版权问题。

---

## 一些实践建议

**小人素材从游戏截图裁切时**,记得把背景抠干净。带背景色块的图在放大跳动时会露出方形边缘,
很破坏观感。用任意抠图工具处理一下,或者干脆选一张背景本来就单一的截图。

**两个小人最好有明显色差**。联机时你需要一眼分清哪个是自己——虽然代码会给自己的小人加一圈
描边,但配色不同会更直观。

**兔子那张图别太写实**。它只显示 32px,而且是「打错了」的负反馈,夸张一点、卡通一点的
效果更好,能把挫败感转成一点幽默。

## 署名

如果使用了需要署名的素材(如 game-icons.net 的 CC BY 3.0 图标),
必须在同目录的 `CREDITS.md` 中按其许可要求列出作者与链接。
