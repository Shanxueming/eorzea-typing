# 专有名词词库

**总计 96,969 条**,22 个分类,外加 2,156 条的精选起步包。

主体是 FF14 国服专有名词,数据源 `thewakingsands/ffxiv-datamining-cn`
(国服客户端 SaintCoinach 解包 CSV)。
重新生成:`python3 scripts/build_wordbank.py`(需先下载 raw/*.csv,详见脚本注释)。

另有一个独立的 **`ff7`(最终幻想7)** 分类,141 条,数据源与构建脚本都和上面无关:
取自 `V-Lipset/ao3-chinese` 的 `glossaries/最终幻想Ⅶ.txt`(**GPL-3.0**),
一份人工维护的 FF7 官方中文译名对照表。
重新生成:`python3 scripts/build_ff7_wordbank.py`。

> ⚠ **两个脚本有先后顺序**:`index.json` 的主体由 `build_wordbank.py` 整体重写,
> 会把 `ff7` 那一条冲掉。跑完 FF14 的构建脚本后,必须再跑一次
> `build_ff7_wordbank.py` 把它并回去(该脚本是幂等的,重复跑不会产生重复条目)。

## 条目结构

```json
{
  "id": "act_00412",
  "text": "必杀剑·九天",     // 显示原文,保留中点
  "typeText": "必杀剑九天",   // 判定文本,已剥离难输入标点
  "reading": "bi sha jian jiu tian",
  "category": "actions",
  "difficulty": 2,           // 1=易(≤3字) 2=中(4-6字) 3=难(≥7字)
  "pure": false              // 是否纯汉字
}
```

### 三个字段的用法

**`text` vs `typeText`** —— 这是本词库最关键的设计。
`必杀剑·九天`、`扇舞·序` 这类带中点的技能名是 FF14 味道最浓的部分,但中点在中文输入法下极难打出。
所以:**界面显示 `text`,判定比对 `typeText`**。玩家看到「必杀剑·九天」,打「必杀剑九天」即可通过。

**`pure`** —— 标记是否为纯汉字。含数字或罗马数字的条目(如 `丰收II`、`4星吨`)在 IME 下需要反复切换输入法,体验差。
建议:**默认只使用 `pure === true` 的条目**,除非做「地狱难度」模式。

**`reading`** —— 拼音,用途有二:①作为提示显示给玩家;②若 IME 判定始终调不通,可降级为「打拼音」模式,绕开输入法问题。

**`named`(仅 characters)** —— 具名角色启发式。
`true` 是像「毕·乔尔」「桑特曼」这样有名有姓的角色(5,512 条),`false` 是「爽朗的卫兵」「开朗的青年」这类路人。
建议游戏内**只用 `named === true`**。注意这是启发式,不完美,仍会混入少量「鲁加族无赖」这类半路人。

## 直接用 starter.json

`starter.json` 已按以下规则筛好,可直接作为游戏默认词库,无需二次处理:

- 只含 `pure === true` 的纯汉字条目
- characters 只取 `named === true`
- 覆盖 14 个分类,每类按难度 1/2/3 均衡取样
- 难度分布:易 767 / 中 794 / 难 595

单机模式让玩家自选分类时,再去读对应的完整分类文件。

## 已知局限

1. **版本滞后**:国服客户端本身落后国际服约一到两个资料片,`items` 与 `quests` 尤其明显。
2. **`items.json` 有 11 MB**,不要整体打进前端 bundle。建议服务端按需读取,或预先抽取子集。
3. **社区黑话没有覆盖**:「光之战士」「水晶公」「坐和放宽」这类梗不在游戏文件里,需人工另建 `memes.json`。
4. **`achievements` 与 `fates` 的非纯汉字比例偏高**(含数字序号),启用前建议按 `pure` 过滤。
5. **`named` 启发式基于「不含『的』字 + 无路人后缀 + 长度 ≤7」**,规则简单,可按需调整 `build_wordbank.py` 中的 `GENERIC_SUFFIX`。
6. **手动订正过的错字**(源数据本身的问题,重新跑 `build_wordbank.py` 会被覆盖回错的,记得重新订正):
   - `places.json` / `starter.json` 的 `plc_00089`:「死都」→「死斗」
   - `quests.json` 的 `qst_00722`:「腐朽魔都」→「腐朽魔斗」
